# ClipSoon 产品规格与验收

## 1. 产品目标

ClipSoon 是一个本地优先、调用迅速的历史剪贴板。用户应能在不离开当前工作流的情况下，
呼出、搜索、预览并发送过去复制过的内容。主窗口不是常驻工作台，而是一个使用时出现、完成
或失焦后隐藏的临时面板。

## 2. 核心用户流程

1. ClipSoon 随应用启动后隐藏并驻留系统托盘；用户开启“开机时自动启动”后，登录系统时自动完成此过程。
2. 用户在任意应用复制文本、图片或本地文件，ClipSoon 在后台记录。
3. macOS 用户默认双击 `Ctrl`（420 ms 内完成两次短按）呼出面板；Windows 用户默认按
   `Ctrl+Shift+Space`，由系统级 `RegisterHotKey` 呼出。
4. 面板出现前记住当前前台应用/窗口；搜索框立即获得焦点。
5. 用户输入关键词，结果按匹配得分排序；同分时按最近复制时间排序。
6. 用户用方向键选择；图片在详情区可预览。
7. 按 `Enter` 或双击结果：ClipSoon 提交完整剪贴板事务；收到系统写入确认后才隐藏并恢复原目标，
   粘贴前再次确认内容仍是本次事务，再发送系统粘贴键。
8. 按 `Esc`、点击外部或切换应用时，面板隐藏但后台继续运行。

## 3. 功能边界

### 必须支持

- macOS 13+、Windows 10/11，Python 3.12。
- 文本、单/多文件、本地图片三类历史。
- 内容哈希去重；相同内容再次复制时更新来源、时间并排到顶部。
- Unicode 不区分大小写搜索；搜索词全部字符必须按顺序出现在条目中。
- 空查询严格按最近复制时间倒序；有查询时严格按匹配得分倒序，同分才按最近复制排序。
- 完全匹配得分最高；其余匹配按查询内容占条目长度比例、连续相邻比例和匹配路径跨度计分。
- 历史列表采用紧凑的 44 px 单行条目，左侧缩略图容器为 30 × 30 px；内容在行内严格垂直居中且上下留白等高，文件图标在缩略图容器内水平和垂直居中且不得越界，不重复显示标题和路径，图片缩略图保持直角矩形、不做圆角裁剪；鼠标所在行以及右键菜单光标所在项均显示弱于选中态但与底色有清晰对比的半选中背景；磨砂主题下选中与悬停必须使用同一蓝调、无描边的材质语言，仅以填充密度区分，不得出现实心蓝块配白色描边卡的混搭；支持与 Finder/资源管理器一致的 Shift/Ctrl 鼠标及键盘扩展多选，并支持通过 Command/Ctrl+A 全选当前 Tab 下的可见列表项；收藏状态以星形标记展示，但不得改变“全部”列表的最近排序；右键菜单按图标、文字、右侧快捷键提示和等值左右留白紧凑定宽；右键可删除所选或确认后清空全部历史，确认使用与当前主题一致的应用内对话框，不显示原生系统问号窗口，操作按钮按文字紧凑定宽。
- 右键菜单的可见项依次为带单色语义图标和右侧快捷键提示的“全选”“收藏”“取消收藏”“删除”“清空”“清空NF”“设置”，其中“全选”作为独立第一组，“收藏”“取消收藏”作为第二组，分组之间必须有分隔线；“收藏”的快捷键为 macOS `⌘D` / Windows `Ctrl+D`，“取消收藏”为 macOS `⇧⌘D` / Windows `Ctrl+⇧+D`；“删除”只删除当前选中的一条或多条记录，快捷键为 macOS `⌘⌫` / Windows `Del`；“清空”清空当前 Tab 的全部历史，不受搜索词或当前可见结果限制，“全部”Tab 清空所有历史，“收藏”Tab 清空收藏历史，快捷键为 macOS `⇧⌘⌫` / Windows `Ctrl+⇧+Del`；“清空NF”清空全部非收藏历史并保留收藏项，快捷键为 macOS `⌥⌘N` / Windows `Ctrl+Alt+N`；“设置”与搜索放大镜共用同一设置入口，快捷键为 macOS `⌘,` / Windows `Ctrl+,`。菜单的图标列与文字之间保持紧凑、稳定的间距，图标加文字整体的左右外边距必须等值且保留足够呼吸感，上下外边距应小于左右外边距，右侧不得残留无意义的额外空白，也不得紧贴文字形成窄条；鼠标悬停或键盘选中的菜单项高亮胶囊到菜单外壳左右两侧的距离必须相等；菜单外壳必须使用圆角矩形四角，不显示生硬直角；菜单文字必须与设置下拉弹层使用同一弹出层字号，不能明显小于主窗口中的列表文字；“设置”必须使用清晰的齿轮语义图标，而非十字/定位符号。确认标题保持“清空历史”：全部 Tab 的提示保持“清空全部剪贴板历史？此操作无法撤销。”；收藏 Tab 的提示显示“清空收藏历史？此操作无法撤销。”；文本、截图、文件 Tab 分别显示“清空剪切板文本历史？此操作无法撤销。”“清空剪切板截图历史？此操作无法撤销。”“清空剪切板文件历史？此操作无法撤销。”；“清空NF”的提示显示“清空所有非收藏历史？此操作无法撤销。”。
- 列表项不显示系统 Tooltip，长文本在列表中单行省略，完整内容只在右侧预览区展示，避免全文浮层跨越屏幕。字体采用接近系统命令面板的层级：搜索框 16 pt、分类 Tab 13 pt、列表主文字、右侧正文预览以及信息区标题/标签/值均为 13 pt；预览框与信息区之间使用两侧内缩、低对比度的细分割线；信息区标题与下方标签严格左对齐，信息区右侧的值与左侧标签使用一致的弱化文字颜色与中等字重，信息区标题保留更高字重；列表与预览必须明显可读且辅助信息不得争夺主内容层级。
- 类型筛选既支持鼠标点击，也支持 Tab 按“收藏、全部、文本、截图、文件”的视觉顺序循环，默认选中“全部”，Shift+Tab 反向循环；切换后搜索框保持可输入。主面板处于激活状态时，搜索框是唯一且持续的输入焦点：点击分类、历史列表、预览、滚动条、放大镜或空白区域均不得改变它；上下键、修饰键扩展选择等列表键盘操作仍由搜索框统一路由。搜索放大镜仅作为鼠标设置入口，系统托盘菜单也保留设置入口。
- 无历史、无匹配搜索或空分类时，列表区显示当前语境的空状态与说明；搜索无匹配时提供“清除搜索”，右侧详情隐藏，结果恢复后立即回到正常列表与详情。
- 面板每次显示时默认切到“全部”、清空搜索并选中完整结果顶部第一项；“记住上次状态”开关默认关闭，开启后可在 1–300 秒内恢复上次类型 Tab 和搜索内容，并按稳定条目 ID 恢复筛选结果中的完整多选集合和当前焦点项，默认记忆 3 秒；即使搜索无结果也必须恢复类型与搜索内容。计时从面板真正隐藏的时刻开始。全局快捷键切换隐藏、失焦自动隐藏、Esc 隐藏和发送后隐藏必须统一在调用 `hide()` 之前记录状态快照和隐藏时刻，`hideEvent` 仅作为系统原生隐藏的兜底且不得重复刷新时间戳。到期时必须主动清空记忆、恢复“全部”并清空搜索内容，并在面板仍隐藏时同步将完整列表、详情和滚动位置重置到第一项，再次显示时使用单调时钟复核；超时、条目已删除或关闭开关时回退到“全部”且无搜索条件下的顶部第一项。
- 主面板不显示独立设置按钮，搜索输入区域不绘制外框，其左右边缘与下方内容区左右边界对齐；搜索框使用 16 pt 文字和 30 px 搜索图标，文字可见区域到输入区域顶部及底部的距离均约为文字高度的一半，避免形成过大的上下空带。搜索下方以及内容区与底部提示之间各保留一条与列表/详情分栏及预览/信息分栏共用样式的低对比度 1 px 横向分隔线；分类 Tab 与内容区之间不绘制横向分隔线，依靠留白维持同一任务流；点击搜索框左侧的放大镜图标打开设置，系统托盘菜单也保留设置入口。
- 设置窗口按“快捷键、历史与行为、数据管理”分区紧凑排列；使用应用自绘的无系统标题栏非阻塞外壳，顶部仅显示“ClipSoon 设置”，底部右侧依次提供“关闭”和“重置”。设置窗口由主面板打开时必须精确居中于主面板可见卡片；不支持拖动、最大化或全屏。关闭不会回滚已生效的修改，重置只恢复设置面板中的默认偏好且窗口保持打开。因为所有参数修改均立即持久化并生效（例如切换“主题”时主面板和设置窗口立刻切换主题），所以设置窗口除底部“关闭”按钮外，还必须支持按 Esc 和点击设置窗口之外关闭，三种关闭路径均不回滚已生效设置，且不得引入“取消”或“保存”按钮；无论设置窗口由主面板放大镜还是系统托盘菜单打开，点击主面板区域、其他应用或桌面空白处都必须关闭设置窗口，托盘菜单打开后的第一次外部点击也必须生效。设置窗口初始焦点停留在窗口外壳，不落到下拉框、输入框或底部按钮；裸按 ↑/↓ 不得修改设置、关闭窗口或触发主面板选中切换，只有用户显式聚焦具体控件后，该控件才处理自己的键盘编辑。设置窗口打开期间，主面板只能作为被强模糊和中性淡化的背景层展示，不得响应 hover、点击、滚轮、右键菜单、搜索输入、上下键选中切换或发送快捷键；背景层文字、文件名和小图标不得可辨认，只允许保留控件大轮廓和色块。Windows 快捷键分区只显示“快捷键”标签和一个组合键录入框，不显示只有单一选项的呼出方式下拉；macOS 保留双击修饰键与组合键模式选择。设置窗口必须与主窗口 13 pt 主内容共享同一视觉尺度：窗口标题约 13 pt，分区标题、输入/下拉/数值框、复选项和按钮约 12 pt，字段标签约 11 pt，说明文字约 10 pt；不得出现大输入框搭配 9 pt 小 label 的断层。字段标签与等宽控件对齐，控件高度与 12 pt 内容匹配且不过度膨胀，表单行距和分区间距必须紧凑但不重叠，不能用大空白弥补字体层级；数字输入不显示突兀的原生步进按钮；行为复选项采用稳定的两列三行节奏，任意系统缩放下均不得重叠；复选框可视方块必须与标签文字同量级，不得明显大于文字高度；输入、下拉、按钮和复选框必须有当前主题一致的聚焦、禁用和勾选状态。三个圆角分区外框使用与主窗口分隔线共用的低对比度 1 px token，不得显示高亮白色描边；磨砂下，闲置的输入、下拉、组合键、数值框、复选框和次要按钮同样使用该 token，聚焦和已选状态仍使用强调色。主搜索和设置中所有实际文字编辑器必须使用当前主题的正文、占位及选择 token；原生 `QLineEdit` 插入光标必须被局部禁绘，并由应用按系统编辑器的 `cursorFlashTime` 节奏自绘同色、闪烁的插入光标。不得出现常亮的自绘竖线，也不得在磨砂主题或设置窗口回退为不可辨识的白色光标。版本信息不在设置窗口重复显示，主窗口右下角采用“↑↓ 选择 | ↵ 发送 | Esc 隐藏 | v1.0.4”的低对比度提示；数据目录入口按平台显示“在 Finder 中打开”或“在资源管理器中打开”，点击后先关闭设置窗口再打开目录，避免设置窗口遮挡文件管理器。
- “磨砂”（内部键 `frosted`）为默认主题，并与浅色、深色两种显式主题一起覆盖主窗口、设置窗口及其非原生弹出层；磨砂固定解析为浅色应用内材质，不随系统明暗变化，且不得启用 Windows DWM 或 macOS NSVisualEffectView 等平台原生背景模糊。设置窗口主题下拉列表不显示独立的“跟随系统”选项，也不显示“磨砂质感（随系统）”。深色设置窗口的应用内容根必须是不透明深色，不能在分区之外露出浅色原生底色或系统标题栏。磨砂必须由单一不透明主材质壳呈现环境色、半透明 veil、上缘高光、双色内外 rim 和随指针移动的柔光；底部和右侧信息区保持浅亮可读，不得出现深蓝色块，且不得透出下方窗口文字，前景文字、列表和控件仍须保持清晰可读。其可见卡片尺寸必须与浅色、深色主题一致。Windows 下主窗口和设置窗口必须通过顶层窗口物理 mask 裁出圆角，圆角外不得残留直角底色；主窗口磨砂材质必须由顶层壳承载，右上角不得露出偏白的 palette 底色。若保留同等尺寸的透明外缘留白，留白下不得显示第二层灰色背景、边距或投影。搜索框可作为唯一的次级功能材质，列表、详情和设置分区不得堆叠成多层“玻璃卡片”。历史列表和长文本预览的垂直滚动条必须作为材质内的窄拇指呈现：轨道、翻页区和两端按钮透明，不能出现整条不透明白色/灰色分隔带。效果不得读取、截取或上传桌面内容，也不得要求屏幕录制权限。历史区与右侧详情区之间必须保留一条低对比度但可察觉的 1 px 垂直分隔线；所有主题下详情列保持透明，不得以整圈边框把它重新包成第二张卡片。设置中的所有下拉列表和历史列表右键菜单必须显式使用当前 ClipSoon 主题的背景与前景色，并为普通、悬停、选中和禁用状态提供清晰对比；实体强调色上的文字与柔光半透明选中面上的文字分别使用可读前景色。不可撤销确认使用危险色的最终操作，普通校验提示仍使用常规强调色；不得因系统主题与应用主题不同而出现浅色背景白字或深色背景黑字。
- 底部状态栏空闲时不显示“准备就绪”等占位文字；记录、删除、暂停和错误等反馈显示约 4 秒后自动清除，连续消息以最新一条为准；缺少 macOS 辅助功能授权时保留可点击的设置入口，授权完成后清除。
- 右侧详情上方显示文本、图片或文件预览，下方信息区首行显示类型，次行按类型显示文件完整路径、图片文件大小或文本字数；图片预览始终等比居中显示，原图能被预览区完整容纳时必须按原始物理像素尺寸映射到当前屏幕 DPR 展示，例如 2x 屏上 162 × 126 像素截图应显示为约 81 × 63 逻辑点，不得为了填满预览区而放大导致模糊，只有原图物理像素超出预览区可容纳物理像素时才等比缩小到完整可见；以本地文件形式复制的单个常见图片也在列表及详情区显示内容预览，同时保留文件发送语义；单个文本文件最多读取开头 4 KB、展示前 220 个字符，未完整展示时末尾另起一行显示 `...`，预览区不响应滚轮、不打开编辑器、不加载完整大文件。主面板激活时搜索框仍是唯一输入焦点；选择文本或文本文件预览中的范围后，`Command+C`（macOS）和 `Ctrl+C`（Windows）必须复制该范围，预览右键菜单项固定为中文“复制”“全选”。
- 图片及图片文件的列表缩略图和右侧大图必须在后台线程解码；点击或键盘移动时先立即更新选中背景、类型和路径，预览区显示加载占位，解码完成后再替换图片；不得因图片尺寸、文件大小或跨项距离阻塞选中反馈。列表缩略图采用 32 MB 字节预算的 LRU 且只保留最终 QPixmap，大图采用 64 MB、最多 12 项的 LRU，预览尺寸按 64 px 分桶；快速切换时撤销排队的旧任务或丢弃旧结果，历史删除时同步失效对应缓存，文件大小或修改时间变化后不得继续命中旧内容。
- 文件历史只保存原路径；单文件或多文件记录中任一路径确定已删除时，整条记录必须由后台检查自动移除。面板呼出不得同步扫描全部历史，发送当前项前必须由有并发上限的后台守护工作线程复核；扫描与删除必须比较持久 revision，不能误删扫描期间重新复制或更新的同 ID 记录；只有对应卷、UNC 共享或映射盘根目录可访问时才能把子路径不存在判为永久删除，权限拒绝、共享断开、移动盘拔出等临时不可用状态不得误删。
- macOS 默认双击 Ctrl，可配置双击 Ctrl/Shift/Alt/Meta 或常规组合键。Windows 默认 `Ctrl+Shift+Space` 且只支持由 `RegisterHotKey` 注册的常规组合键；旧版双修饰键配置必须自动迁移、持久化并提示用户。
- “开机时自动启动 ClipSoon”默认关闭；启用后使用当前用户级启动项在 macOS 登录或 Windows 登录时启动，无需管理员权限。源码运行记录当前虚拟环境 Python，打包运行记录 ClipSoon 可执行文件；保存失败时不得把设置误报为已开启，应用每次启动时应刷新已开启启动项中的可执行路径。
- 无标题栏主面板支持从非文本、非列表、非按钮等空白区域按住鼠标左键拖动；搜索框、列表、预览文字、按钮和其他可交互内容保持原行为。仅在实际移动并松开鼠标后持久化窗口左上角逻辑坐标，后续呼出不得重新居中；多显示器布局改变或原屏幕移除后，旧坐标必须约束回当前可用屏幕内。
- Windows 从全局快捷键首次呼出时，热键宿主必须在触发瞬间保存原前台窗口与实际焦点窗口的 HWND/TID/PID，并尝试向 UI 转交前台激活许可；发送前必须校验这些句柄仍属于原进程/根窗口。普通激活或焦点恢复失败时，只允许由一次性原生 helper 临时附加当前前台、目标和焦点输入队列并重试 `SetForegroundWindow + SetFocus`；Qt GUI 线程不得调用 `AttachThreadInput`。helper 必须在附加前后核验身份、逆序解除且检查结果，父进程最多等待 1.5 秒；无论显式解除是否成功，helper 进程退出都是最终清理边界。桌面客户端异步重建焦点控件时，顶层窗口成功恢复后必须进行有界重试，真正粘贴前仍需核验当前焦点属于原根窗口和已捕获的焦点进程。即使 Windows 最终拒绝前台切换，也必须在面板显示期间通过前台句柄和鼠标按键边沿识别外部点击，且不得影响面板内点击、设置模态框、右键菜单或“失焦隐藏”关闭配置。
- Windows 主面板和设置窗口必须保留普通、非分层的 Qt 顶层 backing store：不得设置 `WA_TranslucentBackground`、创建 Qt 透明分层窗口或走 `UpdateLayeredWindowIndirect` 提交路径，也不得安装会扩大脏区的顶层 `QGraphicsDropShadowEffect`。选择“磨砂”（内部键 `frosted`）时不得请求 DWM Desktop Acrylic，必须只使用浅色应用内磨砂材质，以保持跨平台一致。Windows 10/11 均必须显示清晰可读的应用内磨砂材质壳，不出现黑底、透明黑框、圆角外直角底色或绘制告警。macOS 不启用 `NSVisualEffectView`；界面持久字体使用合法 point size，不得向 Windows 样式传入 `-1`。
- Windows 全局呼出必须只由隔离子进程调用 `RegisterHotKey + MOD_NOREPEAT` 并消费 `WM_HOTKEY`；不得安装 Raw Input、低级键盘 hook 或按键轮询器。持久化配置必须先通过 Win32 热键解析，旧双修饰键及不受支持的组合键必须迁移到默认 `Ctrl+Shift+Space`。热键宿主必须有 500 ms 心跳、启动握手、当前会话唯一实例、父进程死亡退出、每代 nonce 和自动重建；候选组合键注册冲突必须明确报错并自动回滚、持久化及重新注册最近一次 ready 的旧配置。启动时自定义组合键冲突且没有 ready 基线时必须回退默认组合键；默认组合键也冲突时停止回退、保留托盘并明确提示。宿主异常退出后由 supervisor 启动新进程并重新注册。
- Windows 剪贴板读写必须统一由另一个隔离子进程通过原生 Win32 格式完成，UI 主进程不得调用 Qt MIME 读取或 Qt/OLE 写入。采集通知只记录 sequence 与来源窗口，70 ms 后读取，竞争时指数退避；文本、文件、PNG 和 DIB 通过带 session 的私有 manifest 交付。发送时文本必须 eager 写入 `CF_UNICODETEXT`，文件写入 `CF_HDROP + Preferred DropEffect(COPY)`，图片必须同时 eager 写入 `PNG + CF_DIBV5 + CF_DIB`，所有格式都必须使用非空的可移动 `HGLOBAL`，不得依赖延迟渲染或运行时格式合成；三格式图片的原始 32-bit 像素不得超过 128 MiB，避免 GUI 与 helper 双进程出现无界内存峰值。只有 `CloseClipboard` 成功、sequence 相对写入前已推进，且 owner、request marker、必需格式完整验证后才能确认写入；helper 退出后数据仍须可读。目标程序读取兼容格式造成 sequence 合法推进时，粘贴前验证必须在当前稳定 sequence 上重新核对 owner/marker/formats，不得仅因序号不同取消发送；真正的外部覆盖仍必须失败。原生操作卡死必须在 10 秒硬超时后终止；关闭系统剪贴板后的转换落盘应继续报告心跳且最长不超过 120 秒。重建必须回收无主 IPC 文件并从最后成功序号恢复；暂停、清空及自身写回必须使旧代次失效，旧 manifest 不得重新写回历史。
- Enter / 小键盘 Enter / 双击均可发送；输入法界面可见但没有 preedit 组合文本时不得吞掉 Enter，正在组字时第一次 Enter 只确认候选。Windows 收到本次写入 ACK 前不得隐藏面板、激活目标或发送 `Ctrl+V`；目标顶层窗口恢复后允许焦点控件在 240 ms 的有界窗口内异步重建，原焦点或同一根窗口下、同一焦点进程的新焦点验证通过后，才执行粘贴前剪贴板验证。`Ctrl+V` 必须由单次原生 `SendInput` 批量提交四个键盘事件；返回 4 时只报告“已触发粘贴”，返回 0 或部分提交必须保留剪贴板并明确降级，目标客户端是否真正消费仍以真机内容出现为准。验证失败只允许完整重写一次，再失败必须取消自动粘贴；迟到、重复或不匹配响应不得造成二次粘贴。恢复目标窗口时仅对已最小化窗口调用 `SW_RESTORE`，普通或最大化窗口的尺寸状态必须保持不变；复制失败时保留已经成功提交的内容并反馈原因。
- 历史数量、保留天数可配置；图片文件随被清理的历史一并删除。
- 所有历史只保存在本机应用数据目录。
- 权限引导按平台区分：macOS 的辅助功能警告与设置页提供直达系统设置的入口；Windows 不显示该权限要求，只提示管理员权限不对等时的自动粘贴限制。

### 首版明确不做

- 云同步、账户、团队共享、OCR、富文本样式保真、跨设备同步。
- 从 Finder/Explorer 之外的虚拟文件提供器提取尚未落盘的文件。
- 绕过操作系统安全边界；高权限目标窗口和 macOS 辅助功能权限仍受系统约束。

## 4. 可执行验收标准

| 编号 | 场景 | 通过标准 |
| --- | --- | --- |
| A01 | 文本采集 | 复制 Unicode/多行文本后 500 ms 内出现一条文本历史，内容一致 |
| A02 | 文件采集 | 复制单个和多个本地文件后，路径、顺序、数量一致；任一源文件删除后整条记录自动消失，发送前删除也不会写入无效路径 |
| A03 | 图片采集与发送 | 截图或复制图片后保存为 PNG，列表及详情可见且像素尺寸一致；Windows 同时 eager 提交 `PNG + CF_DIBV5 + CF_DIB`，helper 退出后三者仍可读；发送到画图和至少一个 Windows 桌面聊天客户端（如 WeLink）均可粘贴 |
| A04 | 去重 | 同一内容复制两次只有一条记录，时间更新并排到“全部”顶部 |
| A05 | 持久化 | 重启应用后历史、收藏状态和设置仍存在 |
| A06 | 搜索 | 精确最高；短条目高于同连续性的长条目；连续命中高于同长度的离散命中；乱序项排除 |
| A07 | 呼出 | macOS 在 420 ms 内双击 Ctrl 仅呼出一次，长按、Ctrl+其他键、慢速两次不触发；Windows 使用 `Ctrl+Shift+Space` 系统注册键。两平台连续呼出/隐藏 200 轮后仍可继续呼出 |
| A08 | 自定义 | 修改快捷键后旧快捷键失效，新快捷键无需重启即可工作；Windows 候选组合键被占用时自动恢复旧配置和旧注册 |
| A09 | 键盘发送 | 选中结果按 Enter 或小键盘 Enter 后，Windows 必须先收到完整写入 ACK，再隐藏、恢复并验证原顶层窗口与输入焦点、执行粘贴前验证，并以单次 `SendInput` 提交四个事件；系统接受四个事件后提示“已触发粘贴”，真机原应用必须实际出现对应文本/图片/文件；重复/迟到响应不产生第二次粘贴，Windows 输入法仅在真实组字期间保留第一次 Enter |
| A10 | 鼠标发送 | 双击结果行为与 Enter 相同 |
| A11 | 生命周期 | 初始隐藏；Esc 和失焦隐藏；托盘可再次打开和退出 |
| A12 | 清理 | 超过容量或保留期的最旧未收藏记录删除，关联孤立图片同时删除；源文件确定不存在的文件记录（含收藏）自动删除，临时 I/O 故障不误删 |
| A13 | 隐私 | 正常使用无网络请求；数据目录和暂停采集入口清晰可见 |
| A14 | 平台异常 | 权限不足或目标恢复失败时不崩溃，内容仍在系统剪贴板并显示提示 |
| A15 | 状态记忆 | 默认每次显示切到“全部”、清空搜索并选中完整列表第一项；开启记忆后 3 秒内恢复类型 Tab、搜索词、多选和焦点（含无结果搜索），超时或条目失效后恢复“全部”、清空搜索并回退到完整列表第一项 |
| A16 | 主题弹出层 | 浅色、深色和“磨砂”设置下，两个下拉列表及历史右键菜单的普通、悬停、选中、禁用文字均可辨识，应用主题与系统主题不一致时仍不串色；主题下拉列表不显示独立“跟随系统”，也不显示“磨砂质感（随系统）”，并以“磨砂”作为首项和默认项 |
| A17 | 开机自启动 | 默认关闭；开启后写入当前用户级启动项，关闭后删除；源码与打包命令分别正确，注册失败时设置保持原值并反馈原因 |
| A18 | 窗口位置 | 空白区域可拖动，交互控件不可误触发拖动；松开后保存坐标，隐藏重显及重启后位置一致，失效坐标回到可见屏幕 |
| A19 | Windows 生命周期与稳定性 | 快捷键触发时保留原目标 HWND 并完成前台许可交接，呼出后无需点击即可输入和按 Enter；首次激活失败时面板不得在重试前被 Qt 失焦逻辑隐藏，可见但非前台时再次按快捷键必须重新激活；首次快捷键呼出后点击外部即隐藏；字体和窗口绘制无告警；占用剪贴板 5 秒时热键仍能呼出，发送请求会替换被原生读取卡住的剪贴板宿主并以同一 request ID 有界重试；分别结束热键/剪贴板宿主后 2 秒内自动生成且恰好生成一个替代进程并重新注册快捷键；主进程退出后无 helper 遗留；写入或两次验证失败时不得自动粘贴，成功发送后普通/最大化目标窗口保持原尺寸，最小化目标可恢复并接收粘贴 |
| A20 | Windows 磨砂 | 在 Windows 10/11 选择“磨砂”（内部键 `frosted`）后，主面板和设置窗口不得设置 `WA_TranslucentBackground`、不得创建 Qt 透明分层窗口、不得请求 DWM Desktop Acrylic，必须显示固定浅色应用内磨砂材质，不出现黑底、透明黑框、圆角外直角底色、主窗口右上角偏白底色或绘制告警 |
| A21 | 跨平台磨砂 | 在 macOS 13–15、Windows 10/11 与 Linux 选择“磨砂”（内部键 `frosted`）后，主面板、无标题栏设置和确认弹出层均有可见的环境色、上缘高光、细 rim 与交互柔光；磨砂始终使用浅色应用内不透明材质，不随系统明暗变化，且不得启用 macOS `NSVisualEffectView` 或 Windows DWM Desktop Acrylic；底部和右侧信息区保持浅亮可读，不得出现深蓝色块，不得透出下方窗口文字；主面板卡片尺寸与浅/深主题一致，外缘留白不显示第二层原生底；macOS/Linux 的确认弹框只有一个圆角内容卡，卡片外可保留柔和投影但不得露出不透明矩形根背景；历史与长文本预览滚动条无不透明整条轨道；内容层不被多层玻璃遮蔽；不申请屏幕录制权限、不采样桌面 |

## 5. 验证边界

核心搜索、持久化、去重、清理和快捷键状态机可在无头自动化测试中完整验证。窗口视觉、
系统剪贴板格式、全局快捷键权限、跨进程自动粘贴和系统登录启动必须分别在 macOS 与 Windows 真机验收；
其中 A20/A21 的应用内磨砂材质、底部/右侧浅亮度和 Windows 非分层契约可由自动化测试覆盖。macOS 上的本机验收不能替代 Windows 验收。

## 6. 性能预算

- 常驻预热后，快捷键回调到面板 `show()` 完成 p95 小于 100 ms。
- 默认 500 条历史的搜索与排序 p95 小于 20 ms；不允许在输入路径读取 SQLite 或图片原图。
- 列表选中和详情元信息同步更新应在单帧预算内完成；图片缩略图与大图解码不计入该同步路径且不得阻塞 GUI 线程。
- 后台剪贴板变化在 500 ms 内入库；大图 PNG 编码和落盘不得阻塞 GUI 线程。
- 隐藏时的平台健康检查只读取 macOS `NSPasteboard.changeCount` / 快捷键监听状态，或消费 Windows 两个常驻宿主的 500 ms 心跳；Windows 前台句柄和鼠标状态只在面板可见时检查，三个常驻进程合计目标空闲 CPU 小于 0.2%，一次性焦点 helper 只在激活兜底期间存在。
- 默认容量 500 条，列表使用虚拟化绘制，仅解码屏幕内可见的图片缩略图。
